# 키트 원칙: DB 파일

마이그레이션과 SQL 파일을 다룰 때만 불려 오는 원칙이다. 운영 데이터에 닿는 일을 묻는 정책은 사용자 CLAUDE.md의 「올릴 것」이 먼저다.

- 이미 적용된 마이그레이션 파일은 고치지 않고 새 마이그레이션을 더한다. 까닭: 적용 기록과 파일이 어긋나 환경마다 다르게 돌아가는 것을 막는다.
- 운영 상태는 문서와 코드가 아니라 DB 스키마, 함수 본문, 스케줄러 작업, 실제 설정값, 로그로 잰다. 까닭: 코드와 문서가 운영 상태와 다를 수 있다.
- 컬럼, 함수, 설정을 지우기 전에 그것을 참조하는 함수 본문, 뷰, 인덱스, 다른 서비스 설정을 전수 확인한다. 까닭: 지운 뒤 운영에서 참조가 깨지는 것을 막는다.
