# 키트 변경 내역

버전마다 바뀐 것. 업데이트할 때 Claude가 설치본 버전보다 새 항목을 사용자에게 보여 준다.

키트를 고칠 때는 `VERSION`을 바꾸고(같은 날 두 번째 이후 변경은 `YYYY.M.D.N`으로 넷째 자리를 붙인다), 이 설명 문단 바로 아래(이전 항목들 위)에 그 버전 항목을 더한다. 새 항목이 위에 온다. 항목 머리줄은 `## <VERSION과 같은 값>` 한 줄이고, 그 아래에 바뀐 것을 `- ` 목록으로 적는다. 업데이트는 이 머리줄의 버전을 읽어 설치본보다 새 항목을 고른다.

## 2026.10.18

- agent-meter: 백그라운드 작업이 돌거나 응답 중이라 힌트 줄에 shift+tab 안내가 빠지면 표가 권한 모드 표시 폭만큼 오른쪽으로 밀리던 것을 고쳤다.
- agent-meter: 기본 모드(manual mode)와 dontAsk 모드에서도 권한 모드 표시 폭만큼 표를 당긴다.

- 설치 확인의 「남은 자리」 검사를 키트 예시 표가 남았는지 보는 검사로 바꿨다. 이전 `{{` 검사는 아무것도 잡지 못했다.
- 백업이 심볼릭 링크로 둔 `settings.json`, `CLAUDE.md`를 링크가 아닌 내용으로 복사한다.
- switch, restore를 git 확인 목록에서 뺄 때 `git * switch` 꼴까지 열두 항목을 함께 뺀다.
- 훅을 제거할 때 matcher 묶음째가 아니라 이 키트의 명령만 빼서, 같은 묶음에 둔 사용자 훅을 지키게 했다.
- 시험이 Node 18에서도 돈다(Node 22.13부터 있는 `assert.partialDeepStrictEqual`을 쓰지 않는다).
