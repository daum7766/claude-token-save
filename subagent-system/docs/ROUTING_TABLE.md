## 무조건 Opus

<!-- 키트 원본의 예시(백엔드)입니다. 설치할 때 고른 영역 목록으로 바뀝니다 -->
작업 크기와 무관하게 틀리면 되돌리기 어렵거나 시험과 검토에서 드러나지 않는 영역입니다. 이 절의 항목은 모든 프로젝트에 걸리고, 항목을 빼는 것은 사용자 승인을 받습니다.

- DB 스키마 변경과 마이그레이션, 운영 데이터 수정
- 결제, 환불, 잔액처럼 되돌릴 수 없는 금전 기록
- 인증, 권한, 보안
- 동시성, 트랜잭션, 분산 락
- 다른 팀이나 외부가 부르는 API 계약

### 프로젝트별 항목

이 절 아래에 `#### <프로젝트 폴더 이름>` 절을 두고, 그 프로젝트에만 걸리는 영역을 불릿으로 적습니다. 같은 영역이 프로젝트마다 다르게 걸리기 때문입니다.
프로젝트 절이 있는 프로젝트에서는 위 공통 항목에 그 절 항목을 더해 판단하고, 절이 없는 프로젝트는 공통 항목만 씁니다.
